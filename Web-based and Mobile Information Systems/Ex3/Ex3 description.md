# ✅ Άσκηση: Εύρεση Συχνότερης Λέξης με JavaScript

## 🎯 Σκοπός

Να κατασκευάσετε ένα script σε **JavaScript** που να αναλύει ένα κείμενο και να εμφανίζει τη **συχνότερη λέξη** που περιέχει, με ορισμένα φίλτρα και περιορισμούς.

---

## 📥 Είσοδος

- Το κείμενο θα δίνεται από τον χρήστη μέσω ενός **HTML `<textarea>`** στοιχείου.
- Το `textarea` θα πρέπει να έχει `id="input"` για να μπορεί να διαβαστεί από το script.

---

## 🛠 Λειτουργικότητα

1. Ο χρήστης εισάγει το κείμενο στο textarea.
2. Πατάει ένα button, το οποίο καλεί την JavaScript λογική.
3. Η JavaScript:
   - Διαβάζει το περιεχόμενο του textarea με:  
     ```js
     let input = document.getElementById("input").value;
     ```
   - Καθαρίζει το κείμενο από σημεία στίξης.
   - Χωρίζει το κείμενο σε λέξεις.
   - Φιλτράρει λέξεις που έχουν **τουλάχιστον 4 χαρακτήρες**.
   - Μετράει τη συχνότητα εμφάνισης κάθε λέξης.
   - Εμφανίζει με `alert()` τη **λέξη που εμφανίζεται πιο συχνά**.
   - Αν δεν υπάρχει καμία λέξη με 4+ χαρακτήρες, εμφανίζει κατάλληλο μήνυμα στον χρήστη.

---

## 💡 Οδηγίες

- Το script θα πρέπει να βρίσκεται **σε ξεχωριστό `.js` αρχείο**.
- Η σύνδεση της JavaScript με το HTML να γίνεται με `script` tag (π.χ. `<script src="script.js"></script>`).
- Η ενεργοποίηση του script γίνεται μέσω **κουμπιού (button)** με χρήση **HTML5 selector** (π.χ. `addEventListener`).
