# 🛒 Προαιρετική Εργασία: Φόρμα Ανάκτησης Πληροφοριών Προϊόντων

## 📋 Περιγραφή

Ως Web Developer στην εταιρεία σας, καλείστε να δημιουργήσετε μια **onepage ιστοσελίδα** για ένα ηλεκτρονικό οπωροπωλείο, η οποία θα περιέχει:

- **Header**
- **Product Price Table**
- **Product Info List**
- **Footer**

---

## 🏗️ Απαιτήσεις

### 1. Header

- Περιλαμβάνει τον τίτλο ή το λογότυπο της ιστοσελίδας.

### 2. Product Price Table

- Τα δεδομένα των προϊόντων θα είναι αποθηκευμένα σε έναν **PHP array**.
- Να εμφανίζονται σε μορφή **HTML5 πίνακα (table)** με στήλες όπως: Όνομα Προϊόντος, Τιμή, Διαθεσιμότητα κ.ά.
- Ο πίνακας πρέπει να είναι καθαρός και ευανάγνωστος.

### 3. Product Info List

- Υπάρχει μια **dropdown λίστα (select element)** που περιέχει τις ονομασίες των προϊόντων.
- Όταν ο χρήστης επιλέγει ένα προϊόν από τη λίστα, να εμφανίζονται τα αντίστοιχα **περιεχόμενα και πληροφορίες** αυτού του προϊόντος (π.χ. περιγραφή, θρεπτικά στοιχεία, προέλευση).
- Η εμφάνιση των πληροφοριών γίνεται στην ίδια σελίδα, χωρίς ανανέωση (μπορεί να γίνει με απλό PHP ή JavaScript, ανάλογα με την υλοποίηση).

### 4. Footer

- Περιλαμβάνει στοιχεία όπως πηγή πληροφοριών, copyright, ή άλλα σχετικά links.

---

## ⚙️ Τεχνικά

- Η σελίδα να είναι **single-page**.
- Η χρήση **PHP** είναι απαραίτητη για την ανάκτηση των δεδομένων του πίνακα.
- Η εμφάνιση και επιλογή πληροφοριών προϊόντων να γίνεται δυναμικά.
- Μπορείτε να χρησιμοποιήσετε απλή HTML, CSS και JavaScript όπου χρειάζεται.
- Να διατηρείται καλός διαχωρισμός δομής, στυλ και λογικής.

---

## 🧾 Υποβολή

Παραδοτέο: Ένα αρχείο `.zip` με:

- `index.php` ή `index.html` + απαραίτητα PHP αρχεία
- Αρχεία CSS και JS αν υπάρχουν
