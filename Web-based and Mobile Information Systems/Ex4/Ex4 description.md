# 💼 Προαιρετική Εργασία: Υπολογισμός Καθαρού Εισοδήματος

## 📝 Εκφώνηση

Καλείστε να κατασκευάσετε μια ιστοσελίδα που θα υπολογίζει το **καθαρό εισόδημα** ενός εργαζόμενου με βάση τον παρακάτω πίνακα **υπολογισμού φόρου**:

### 📊 Πίνακας Υπολογισμού

| Εισόδημα (€)       | % Φόρου | Αφορολόγητο (€) | % Έκπτωσης |
|--------------------|---------|------------------|-------------|
| < 8.000            | 10%     | 6.000            | 20%         |
| 8.000 - 15.000     | 20%     | 6.500            | 10%         |
| 15.000 - 40.000    | 32%     | 4.000            | 10%         |
| > 40.000           | 40%     | 2.000            | 5%          |

---

## 📥 Είσοδος Χρήστη

Ο υπολογισμός θα βασίζεται στα εξής στοιχεία, τα οποία θα εισάγονται από τον χρήστη μέσω φόρμας:

- ✏️ **Ετήσιο Εισόδημα**
- 📅 **Ημερομηνία Γέννησης**
- 👨‍👩‍👧‍👦 **Αριθμός Τέκνων** (μέγιστο: 4)

---

## 📐 Υπολογισμοί

Το τελικό εισόδημα υπολογίζεται με βάση τα παρακάτω:

1. **Φορολογητέο Εισόδημα (ΦΕ)**:
ΦΕ = Εισόδημα - Αφορολόγητο

2. **Αρχικός Φόρος**:
Φόρος = ΦΕ * % Φόρου


3. **Τελική Έκπτωση (%Έκπτωσης.Τελ)**:
%Έκπτωσης.Τελ = %Έκπτωσης + (5% * Αρ. Τέκνων)


- ⚠️ Μέγιστος αριθμός τέκνων: **4**
- Η **% Έκπτωσης** εφαρμόζεται **μόνο** αν ο χρήστης είναι:
  - κάτω των **25 ετών**, ή
  - άνω των **65 ετών**

4. **Τελικός Φόρος (Φόρος.Τελ)**:
Φόρος.Τελ = Φόρος - (Φόρος * %Έκπτωσης.Τελ)


5. **Καθαρό Εισόδημα (ΚΕ)**:
ΚΕ = Εισόδημα - Φόρος.Τελ

---

## 🧪 Παράδειγμα Υπολογισμού

**Είσοδος Χρήστη:**

- Ετήσιο Εισόδημα: **22.000 €**
- Ημερομηνία Γέννησης: **01/01/1990**
- Αριθμός Τέκνων: **2**

**Υπολογισμοί:**

- Ανήκει στην κατηγορία **15.000 - 40.000**:
- % Φόρου = **32%**
- Αφορολόγητο = **4.000 €**
- % Έκπτωσης = **0%** (δεν είναι <25 ή >65)

1. **ΦΕ** = 22.000 - 4.000 = **18.000**
2. **Φόρος** = 18.000 * 0.32 = **5.760 €**
3. **%Έκπτωσης.Τελ** = 0 + (2 * 5%) = **10%**
4. **Φόρος.Τελ** = 5.760 * (1 - 0.10) = **5.184 €**
5. **Καθαρό Εισόδημα (ΚΕ)** = 22.000 - 5.184 = **16.816 €**

## ✅ Τεχνικές Οδηγίες

- Η υλοποίηση πρέπει να γίνει με **HTML + JavaScript**.
- Η **λογική υπολογισμού** να βρίσκεται **σε αρχείο `.js`**.
- Η είσοδος να παρέχεται μέσω **φόρμας** (`input`, `date`, `number`).
- Το αποτέλεσμα μπορεί να εμφανίζεται είτε με **`alert()`**, είτε με προβολή σε κάποιο **`div`**.

---

## 🧾 Τι Να Υποβληθεί

Υποβάλλετε ένα `.zip` αρχείο που να περιέχει:

- `index.html`: η φόρμα εισόδου και εμφάνισης
- `script.js`: όλη η λογική υπολογισμού
