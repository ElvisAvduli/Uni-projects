# Προαιρετική Εργασία Responsive Layout με HTML & CSS

## Περιγραφή

Υλοποιήστε μια **single-page responsive** ιστοσελίδα χρησιμοποιώντας **απλή HTML και CSS**. **Δεν επιτρέπεται** η χρήση JavaScript, jQuery, Bootstrap ή άλλων βιβλιοθηκών.

Σας δίνονται τρεις όψεις μιας σελίδας. Η σελίδα αποτελείται από **4 τμήματα (sections)** με περιεχόμενο.

Είστε **ελεύθεροι** να χρησιμοποιήσετε οποιοδήποτε κείμενο θέλετε (π.χ. αγαπημένα φαγητά), καθώς και **οποιοδήποτε χρώμα**, αρκεί να διατηρηθούν οι σχεδιαστικές διαφοροποιήσεις:

- Όλα τα sections το ίδιο χρώμα background.
- Όλοι οι τίτλοι διαφορετικό χρώμα.
- Background διαφορετικό από τα περιεχόμενα.

---

## Ανταποκρισιμότητα (Responsive Behavior)

Η ιστοσελίδα πρέπει να **προσαρμόζεται ανάλογα με το μέγεθος της οθόνης**:

- **Desktop view**: οθόνες > 992px
- **Tablet view**: μεταξύ 768px και 427px
- **Mobile view**: οθόνες < 427px

Το **layout των sections πρέπει να αναδιατάσσεται** χρησιμοποιώντας **Flexbox**, σύμφωνα με το μέγεθος της οθόνης.

---

## Προδιαγραφές Layout

- Όλα τα sections πρέπει να:
  - Περικλείονται από **border**
  - Έχουν **απόσταση** μεταξύ τους
  - Έχουν **περιθώριο (padding)** ανάμεσα στο border και στο κείμενο/τίτλο

---

## Παραδοτέο

- Ένα `.zip` αρχείο που περιέχει:
  - `index.html`
  - `styles.css`

---

## Προαιρετικά (Extras)

Μπορείτε να ενισχύσετε τη σελίδα σας με:

1. **Footer**:
   - Περιέχει πηγή του κειμένου σας ή κάποιο άλλο link
   - Το link να **αλλάζει χρώμα με hover**

2. **Εικόνες σε sections**:
   - Το κείμενο να **τυλίγεται γύρω από τις εικόνες**
   - Οι εικόνες να **παραμένουν εντός του border**, ανεξαρτήτως μεγέθους οθόνης
