# 🔐 Άσκηση: Φόρμα Login με Cookie "Remember Me"

## 📋 Περιγραφή

Καλείστε να υλοποιήσετε μια σελίδα **login** με τα παρακάτω στοιχεία:

- **Inputs:**
  - `username`
  - `password`
- **Radio button** με όνομα **"Remember Me"**
- **Submit button**

---

## 🎯 Στόχος

- Να χρησιμοποιηθεί **PHP** για την αποθήκευση των στοιχείων του χρήστη σε **cookie**.
- Όταν ο χρήστης ξαναμπεί στη σελίδα login, τα στοιχεία να **συμπληρώνονται αυτόματα** αν υπάρχει cookie.

---

## 🔄 Συμπεριφορά εφαρμογής

- **Αν ο χρήστης έχει τσεκάρει το "Remember Me":**
  - Να αποθηκεύονται τα στοιχεία (`username` και `password`) σε cookie.
  - Να τον κατευθύνει σε μια σελίδα με μήνυμα επιτυχίας.
  - Να υπάρχει σύνδεσμος για επιστροφή στη σελίδα login όπου τα στοιχεία θα είναι προσυμπληρωμένα.

- **Αν δεν έχει τσεκάρει το "Remember Me":**
  - Να εμφανίζεται κατάλληλο μήνυμα (π.χ. "Δεν αποθηκεύθηκαν τα στοιχεία").
  - Να μην αποθηκεύονται cookies.
  - Να υπάρχει σύνδεσμος για επιστροφή στη σελίδα login.

---

## 🧾 Υποβολή

- Αρχεία `.php` που περιλαμβάνουν:
  - Τη σελίδα login με τη φόρμα.
  - Τη σελίδα επιτυχίας / ενημέρωσης.
- Δυνατότητα αποθήκευσης και ανάκτησης δεδομένων μέσω cookies.
